# 🏥 Doctor Appointment Booking System

A **full-stack doctor appointment system** built using the **MERN Stack (MongoDB, Express, React, Node.js)**. The application includes **patient**, **admin**, and **doctor panels**, supports **online appointment booking**, **secure login systems**, and **online payments**.

---

## 🚀 Features

* 👩‍⚕️ Doctor Listings & Profiles
* 📅 Appointment Booking & Cancellation
* 💳 Online Payment Integration
* 🧑‍⚕️ Doctor Dashboard
* 🧑‍💼 Admin Panel to Manage Doctors & Appointments
* 👨‍⚕️ Patient Profile Management
* 📱 Fully Responsive Design
* 🔐 Login & Registration for Admins, Patients, and Doctors

---

## 🧩 Tech Stack

### Frontend

* React.js
* Tailwind CSS
* Axios
* React Router

### Backend

* Node.js
* Express.js
* MongoDB & Mongoose
* JWT Authentication
  
---

## 🔑 Environment Variables

Create a `.env` file in your `server/` folder:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
STRIPE_SECRET_KEY=your_payment_secret_key
```

---

## 🧪 Run Locally

1. **Clone the repository**

```bash
git clone https://github.com/yourusername/doctor-booking-app.git
cd doctor-booking-app
```

2. **Install dependencies**

```bash
# Backend
cd server
npm install

# Frontend
cd ../client
npm install
```

3. **Run both servers**

```bash
# Backend
cd server
npm run dev

# Frontend
cd ../client
npm start
```      |
